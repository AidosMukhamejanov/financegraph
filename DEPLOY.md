# Запуск и проверка демо

После установки `pip install -r requirements.txt` запускайте `python start.py`.
Эта команда пересобирает parquet → CSV/graph.json перед запуском API: старый артефакт не останется после обновления кода.

В настройках окружения серверного сервиса Render/Railway задайте:

- `OPENAI_API_KEY`: действующий секретный ключ проекта с доступом к API. Не размещать во фронте или git.
- `OPENAI_MODEL`: `gpt-4o-mini` (или доступная Chat Completions модель с function calling).
- `CORS_ORIGINS`: адрес отдельного фронта, например `https://example.com`; несколько адресов через запятую.
- `PORT`: обычно задаётся хостингом автоматически.

Start command: `python start.py`. После изменения переменных перезапустите сервис.
`GET /api/health` показывает наличие конфигурации, но не проверяет валидность ключа.
Реальная проверка: отправить `POST /api/ask` и получить `mode=llm` с непустыми `steps`.
При отказе ответ содержит `mode=fallback`, `llm_error` и сохранённые результаты инструментов.
`not_configured` означает отсутствие ключа; `AuthenticationError` — ошибку авторизации;
`RateLimitError` — ограничение API; `TimeoutError` — общий лимит 25 секунд.

Пример тела: `{"question":"Кто получает от выбранных узлов?","selected_gids":["100000000343175100"]}`.
Передавайте gid строками из исходных данных: int64 данного набора превышают точность JavaScript Number.
Числовой формат ответа сохранён для совместимости; фронту нужен lossless JSON parser для точных gid.

`GET /api/graph`: `Cache-Control: no-store`, заголовок `X-Graph-Version`, поле `meta.build_id`.
`clusters[].role_counts` вычисляется из тех же узлов; проверка выполняется при сборке.
Если на фронте другие количества ролей, сравните `meta.build_id` ответа API и загруженного файла.

## Интерпретация ролей

Coordinator: ≥3 различных seed-предка и ≥2 прямых отправителя, после distributor/consolidator.
Дополнительное условие отличает точку слияния от её потомка с единственной входящей связью.
Seed не считается собственным предком даже в цикле. Terminal: вход >0, выход ≤10%,
не cutoff и не seed/курьер. Это гипотеза накопления в июльской выборке, а не полный баланс.
Долю terminal нельзя оценивать без распределения входов/выходов; пороги не подгоняются под желаемый процент.

Проверки: `python -m unittest discover -s tests -v`.
Тест function calling использует имитацию SDK; реальный вызов требует серверного ключа.
